# Start date passed, no hours

**What good looks like.** First check with the ops manager why the job has not
started (crew, materials, permits, weather). Then tell the customer the new
start date in writing. Record the contact; mention the reason only when it is
ours to share.

**When nothing is needed.** The customer asked to delay, or the ticket is a
placeholder that ops will reschedule: **Noted** with who said so.

**When to escalate.** More than seven days past start with no new date: assign
work to the ops manager to set the date, due the next business day.

**Who to contact.** The primary contact, and the site contact when access is
involved.
